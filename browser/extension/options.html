Privacy settings

Applies to top-level GET requests. Turn this off if a signed link or a site breaks.

Queries stay in the browser. No public search provider is configured.

Use Firefox's settings to delete browsing data, manage site permissions, or change tracking protection. Quill's Rust vault is not connected to Firefox's password manager.

Quill update checking: Off. The prototype has no update network client.

This development extension cannot audit all engine connections, DNS, WebRTC or OS traffic. Private windows use Firefox's built-in page; the extension does not run there.
