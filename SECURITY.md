# Security

This is pre-release development software. Do not use its experimental vault for
real credentials or its development browser profile for sensitive browsing.
No stable release currently receives security support.

Report vulnerabilities using GitHub's private vulnerability reporting for this
repository if enabled. If unavailable, open an issue asking for a private contact
without exploit details or personal data. Never attach a real browser profile.

Keep the Firefox host current. The prototype deliberately does not replace
Mozilla's security team or ship an unattended updater. Release readiness requires
engine patch ownership, signed packages, independent review, and a response policy.
